# Analisador-de-Estruturas
Neste projeto elaboraremos um software com interface gráfica que facilite e auxilie o estudo de mecânica de estruturas. 
# Conceito
 O programa será implementado, a princípio, como um site na web, facilitando o acesso do público. As funcionalidades deste software serão:
- Automatizar o cálculo de reações em apoios em diversas estruturas planas.
- Possibilidade de gerar diagramas de esforços solicitantes.
- Permitir o desenho de estruturas mais simples.
- Ter uma seção com explicações didáticas e lúdicas sobre o conteúdo.
